# Portfolio

Personal site — React, TypeScript, Vite, Tailwind CSS, Framer Motion, React Three Fiber / Three.js, Lenis.

## Scripts

```bash
npm run dev      # local dev
npm run build    # production build
npm run preview  # preview build
npm run lint
```

The site tracks:

- Section visibility (first in-view)
- Navigation interactions (desktop + mobile)
- CTA clicks
- External/social/email link clicks
- Theme toggles and back-to-top clicks
